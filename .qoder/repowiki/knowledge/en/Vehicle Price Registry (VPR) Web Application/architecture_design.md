The app is intentionally flat: every top-level .php file is a self-contained page entry point with no framework routing. All cross-cutting concerns — database access, schema migrations, security helpers, admin authentication, Paynow/ZiG payment flows, search finalization, and backup/migration logic — live in the single shared core library db.php, which every child module imports. Child modules (public_search_and_certificate, paynow_usd_payments, admin_console, plus ZiG payments, Excel backup/migration, traffic reports, legal/static pages) are distinguished only by their entry scripts and the feature they expose; there is no layered package structure. The data directory holds the SQLite database (vpr.sqlite) plus an .htaccess to deny direct access, and versioned release notes under Documentation/ track per-release changes rather than code branches.
