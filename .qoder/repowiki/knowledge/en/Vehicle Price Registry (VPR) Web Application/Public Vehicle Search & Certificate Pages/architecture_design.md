Three flat, self-contained PHP scripts that each `require_once __DIR__ . '/db.php'` to obtain shared helpers (`security_headers`, `secure_session_start`, `admin_session_valid`, `vpr_price`, `certificate_number_for_row`, etc.) — no internal sub-packages. `index.php` is the public landing form: it renders a registration-number + brand/model/chassis search, fetches live USD/ZIG fees via `vpr_price`, and uses an embedded JavaScript flow to open a Paynow popup (USD) or a direct ZiG Paynow link, then polls `paynow_status.php` until payment confirmation before redirecting to the certificate URL. `domain_check.php` is an admin-only diagnostic that runs after `admin_session_valid()` and reports HTTPS status, current host, SQLite/writable checks, and presence of `.htaccess` files. `certificate.php` renders a print-ready A4 report for a given search ID, gated by either an admin session or a per-search `access_token` compared with `hash_equals`; it loads interests from `search_interests` (with a legacy fallback to the old `interests` table) and outputs styled HTML with `@page`/`@media print` rules for PDF export. Dependency direction is one-way: these pages depend on `db.php` and on sibling endpoints (`paynow_create.php`, `paynow_status.php`) but expose no shared API themselves.
